# KZ Life Insurance Analytics

Интерактивный дашборд по рынку страхования жизни Казахстана: 10 компаний по страхованию жизни (КСЖ), премии и выплаты по классам, доли рынка, помесячная динамика, сравнение год к году и история рынка 2022–2026.

**Данные:** Национальный Банк РК (январь–октябрь 2026, по 01.11.2026) и обзор АРРФР (на 01.10.2026).

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Сайт: разметка, стили и графики (d3.js) |
| `data/*.json` | Наборы данных: `kpi`, `companies`, `classes`, `company_classes`, `monthly`, `yoy`, `history` |
| `pro.md` | Описание проекта: цели, источники, методология, регламент обновления |

## Запуск локально

Страница загружает данные через `fetch`, поэтому её нужно открывать через веб-сервер, а не двойным щелчком по файлу. Например:

```
python -m http.server 8000
```

и открыть http://localhost:8000.

## Обновление данных

Раз в месяц замените файлы в `data/` новыми выгрузками (формат `{"rows": [...]}`) и сделайте коммит — GitHub Pages обновит сайт автоматически.

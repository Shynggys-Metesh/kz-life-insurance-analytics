# Financial Intelligence Kazakhstan

Аналитическая платформа страхового рынка Республики Казахстан. Сейчас готов **этап 1 — UI/UX-прототип** по техническому заданию: 12 разделов, графики Apache ECharts, расчётный модуль с тестами и центр импорта с проверкой данных.

**Данные:** Национальный Банк РК (январь–октябрь 2026, по 01.11.2026) и обзор АРРФР (на 01.10.2026). Разделы без фактических данных помечены **DEMO DATA**.

## Разделы

| Раздел | Данные |
|---|---|
| Executive Dashboard, Страхование жизни, Компании, Пенсионные аннуитеты, Структура рынка (HHI, CR3/CR5) | НБК, АРРФР + расчёты |
| Финансовые результаты, Активы и обязательства | НБК; динамика доходов и структура обязательств — DEMO |
| Общее страхование | DEMO |
| Data Import Center | работает в браузере: CSV/XLSX, предпросмотр, сопоставление со справочником, проверка; без сохранения |
| AI Analytics Builder | не подключён (этап 6), запросы не обрабатываются |
| Отчёты | экспорт CSV/XLSX, PNG графиков, печатный отчёт → PDF |
| Администрирование | роли по ТЗ; пользователи и журнал — DEMO |

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `js/app.js` | оболочка приложения и навигация |
| `js/views.js` | разделы |
| `js/calc.js` | расчётный модуль (рост, доли, YoY, HHI, CRn, уровень выплат) |
| `js/catalog.js` | справочник показателей и aliases |
| `js/charts.js`, `js/ui.js`, `assets/app.css` | дизайн-система, тема ECharts, компоненты |
| `data/*.json` | данные НБК и АРРФР |
| `scripts/extract.py`, `scripts/build.py` | чтение файлов НБК и расчёт наборов данных |
| `tests/calc.html` | автотесты расчётов (открыть в браузере) |
| `docs/ARCHITECTURE.md` | целевая архитектура, модель данных PostgreSQL, план этапов |
| `pro.md` | описание проекта |

## Запуск локально

Страница загружает данные через `fetch`, поэтому её нужно открывать через веб-сервер:

```
python -m http.server 8000
```

и открыть http://localhost:8000. Тесты — http://localhost:8000/tests/calc.html.

## Обновление данных

Раз в месяц замените файлы в `data/` новыми выгрузками (формат `{"rows": [...]}`) и сделайте коммит — GitHub Pages обновит сайт автоматически.
